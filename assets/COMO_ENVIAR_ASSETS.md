# Onde colocar seus arquivos oficiais

## Ícones
Coloque os PNGs/WebP com fundo transparente em:

| Pasta | Uso |
|-------|-----|
| `assets/icons/nav/` | Home, Treinos, Hábitos, Evolução, Perfil |
| `assets/icons/features/` | Água, Corrida, Sequência, Receitas, Áudios, Calendário, Desafios, Vídeos, Comunidade, Amanda IA |
| `assets/icons/achievements/` | Medalhas / conquistas |
| `assets/icons/misc/` | Outros |

**Preferência de nome (exemplo):**
- `nav_home.png`, `nav_workouts.png`, `nav_habits.png`, `nav_evolution.png`, `nav_profile.png`
- `feat_water.png`, `feat_run.png`, `feat_streak.png`, …
- `ach_first_workout.png`, `ach_7_days.png`, …
